PromptVault — Privacy Policy

Last updated: April 14, 2026

Summary: PromptVault does not collect, store, or transmit any personal data to IA Squared Extensions servers. All user data (prompts, settings, license key) is stored exclusively on your device using chrome.storage.local. The only third-party communications are: (1) direct API calls to your chosen AI provider using your own API key, and (2) license validation with Gumroad when activating a Pro license.

1. Overview

PromptVault ("the Extension") is a Chrome browser extension developed by IA Squared Extensions. This Privacy Policy explains in full what data the Extension accesses, how that data is collected, used, stored, and shared, and what rights you have over your data. This policy applies to all users of the PromptVault Chrome extension.

2. Single Purpose Statement

PromptVault is a universal AI prompt library that allows users to save, organize, search, and inject saved prompts directly into AI platforms including ChatGPT, Claude, Grok, Gemini, and Perplexity. The Extension does not perform any function unrelated to this core purpose.

3. Data Collection: What We Collect and How

IA Squared Extensions does not operate any server that collects or receives user data. All data generated or entered by the user is stored locally on their device only, using the browser's built-in chrome.storage.local API. The following data types are stored locally:

Data Type What It Contains Why It Is Stored Where It Is Stored Shared With
Prompt Library Prompt titles, text content, tags, and usage counts entered by the user Core feature: allows users to save and reuse prompts Device only (chrome.storage.local) Nobody
Settings & Preferences Theme (light/dark), language, feature toggles To persist user preferences across sessions Device only (chrome.storage.local) Nobody
AI API Key User-provided Anthropic or OpenAI API key (optional) To make AI enhancement calls on the user's behalf using their own key Device only (chrome.storage.local) Sent directly to the user's chosen AI provider (OpenAI or Anthropic) only when the user explicitly triggers an AI feature
Pro License Key Gumroad license key entered by the user To verify Pro subscription status Device only (chrome.storage.local) Sent to Gumroad's API for validation only
Usage Counts Daily count of prompt injections or AI calls To enforce free plan usage limits Device only (chrome.storage.local) Nobody

4. Data We Do NOT Collect

IA Squared Extensions does not:

  • Collect or transmit personal information (name, email, address, phone number) to any server we operate
  • Track your browsing history or behaviour across websites
  • Read the content of pages you visit beyond detecting which supported AI platform you are on
  • Share any data with third parties for advertising, marketing, or analytics purposes
  • Use cookies, pixel trackers, fingerprinting, or any other tracking technology
  • Sell, rent, or trade any user data
  • Retain any user data on developer servers — we operate no such servers

5. Data Use

Data stored locally on your device is used solely to operate the Extension's features: displaying your saved prompt library, applying your preferences, enforcing usage limits on the free plan, and verifying your Pro license status. No data is used for profiling, behavioural advertising, or any purpose beyond directly serving you within the Extension.

6. Data Sharing and Third Parties

IA Squared Extensions does not sell or share user data with any third party for commercial purposes. The only external communications initiated by the Extension are:

  • AI providers (OpenAI, Anthropic): When you use AI prompt-enhancement features and have provided your own API key, your prompt text is sent directly from your browser to the selected AI provider's API. This communication is governed entirely by that provider's privacy policy. IA Squared Extensions does not see, intercept, log, or store the content of these requests or responses. See: OpenAI Privacy Policy, Anthropic Privacy Policy.
  • Gumroad (license validation): When you activate or verify a Pro license, your license key is sent to Gumroad's API (api.gumroad.com) solely to confirm its validity. IA Squared Extensions does not receive or store any payment information. See: Gumroad Privacy Policy.

Beyond the above, no user data is shared with any other third party under any circumstances.

7. Permissions Justification

The Extension requests only the minimum permissions necessary to operate:

  • storage: Stores the user's prompt library, settings, API key, license key, and usage counts locally on the device using chrome.storage.local. No data is transmitted to developer servers.
  • host_permissions (chat.openai.com, claude.ai, grok.com, gemini.google.com, perplexity.ai): Required to inject the PromptVault sidebar UI into supported AI platforms so users can browse and insert saved prompts into input fields on those pages.

8. Data Retention

All data stored by the Extension persists in your browser's local storage until you explicitly delete it (via the Extension's settings) or uninstall the Extension. IA Squared Extensions retains no copies of your data on any server. Uninstalling the Extension removes all locally stored data from your device.

9. Data Security

All data is stored using the browser's native chrome.storage.local API, which is sandboxed to the Extension and inaccessible to websites or other extensions. API keys are stored in local storage only and are never transmitted except directly to the user's chosen AI provider when the user explicitly invokes an AI feature.

10. Children's Privacy

This Extension is not directed at children under the age of 13. We do not knowingly collect personal information from children. If you believe a child has provided information through this Extension, please contact us and we will take appropriate action.

11. Your Rights

Because all data is stored locally on your device and no data is held on developer servers, you have full control over your data at all times. You may:

  • View all stored data within the Extension's settings panel
  • Delete your prompt library and settings at any time via the Extension's settings
  • Uninstall the Extension to remove all locally stored data

For users in the European Economic Area (EEA), United Kingdom, or California, you have additional rights under GDPR, UK GDPR, and CCPA respectively. As we hold no personal data on our servers, these rights are exercised by managing data within the Extension itself. For any questions, contact us at the address below.

12. Changes to This Policy

We may update this Privacy Policy from time to time. When we do, we will update the "Last updated" date at the top of this page. Continued use of the Extension after changes constitutes acceptance of the updated policy. We encourage you to review this policy periodically.
